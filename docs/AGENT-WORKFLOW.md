# 智能体运行方式

只读取真实数据。默认接入四平台当前接口全部作品、已采集评论和互动快照。没有内置事件清单、虚拟评论、确定性演示分析或失败回退样本。

1. 从已配置 HTTP 接口加载作品与互动字段。
2. 模型按具体事件归并尚未分组的作品，校验作品 ID。
3. 按事件分析实际材料，摘要和每条发现保留原文证据。
4. 输入变化时旧报告失效，新增发现去重提醒。
5. 编辑按需查看来源、核实疑问并记录实际改进。

默认先单次测试。开启 MODEL_AUTO_ANALYZE 后，页面打开期间按 1/5/15 分钟间隔分页刷新各平台全部已有作品，读取详情及评论、归并新作品并分析变化事件。只有观测时间改变时不重复调用。默认不限制每小时模型请求次数（`MODEL_MAX_CALLS_PER_HOUR=0`）；失败会显示原因，保留上次成功数据，不伪造结论。

关闭页面后不运行，没有服务端常驻调度。当前事件归属保存在本地文件，报告在浏览器保存。后续数据库统一采用 MongoDB，增加任务记录、分析版本、证据审计与增量游标。详见 [接入说明](LIVE-INTEGRATION.md) 和 [存储规划](STORAGE.md)。

全量接入不等于同时分析全部数据。每轮归并最多40篇，每批12篇，已完成批次即时保存；默认不设每小时调用上限，仍保留分批处理与单任务调用预算。归并期间暂停启动事件分析，避免两类模型任务相互抢占。超过40篇作品或100条评论的大事件保留完整材料，待后续分块分析；不截断数据假装全量结论。
