# 全量真实数据接入

更新于2026-11-06。全量指当前用户接口中已经收录且可返回的数据，不代表平台全网数据。

## 实测范围

首次验证读取1022篇作品：抖音652、微博240、小红书70、公众号60；55条评论含2条子评论，4333条互动快照。数据会持续变化，页面展示当前成功读取的数量及各平台接口总数。

仅使用用户已有的只读服务，不启动上游采集任务，不引入虚拟数据。未新增数据库；未来本系统的持久化仍采用MongoDB。

## 读取方式

- `/api/works` 按平台遍历所有分页，每页最多200条。每页检查总数、偏移和返回数量，不把中途失败或重复分页当作完整数据。
- 读取每篇作品的 `/api/works/{platform}/{external_work_id}`，并发默认4，上限8。保留正文、原链接、互动原值、阅读量、增量、快照及已采集评论。
- 按作品ID和观测数据复用最近详情；最长5分钟复查一次，避免评论更新没有改变作品时间戳而永久遗漏。缓存仅在进程内，重启后重新读取。
- 首次加载约需十几至几十秒，取决于数据量和接口速度。整批校验成功才替换上次成功数据；失败不返回虚拟或静默截断的结果。
- 微博、小红书的详情含评论正文。保留父评论、根评论ID、作者、时间、点赞和回复数量。评论ID包含平台与作品ID，避免不同作品间碰撞。缺失父评论、跨作品回复、循环和重复ID会明确报错。
- 抖音、公众号当前没有评论正文。平台评论统计数与已收录原文数分开，不能从统计数推断受众观点。
- 百度/今日头条热点与竞品数据没有现成接口，仍显示缺口。详情的 `comment_total` 代表已采集原文，不代表平台全部评论。

配置：

```dotenv
DATA_SCOPE=all
DATA_PAGE_SIZE=200
DATA_LOAD_DETAILS=true
DATA_DETAIL_CONCURRENCY=4
```

`DATA_LIMIT_PER_PLATFORM` 只在显式配置 `DATA_SCOPE=latest` 时生效，不再限制默认全量模式。密钥及模型配置不随本次接入重写。

## 页面与模型边界

“数据与设置”显示全部作品、已采集评论、互动快照、事件及待归并作品数。全域信息流每次展示100条，后续数据继续显示；筛选和总数基于完整数据。评论列表每次展示50个讨论串，可继续显示。事件弹幕只展示已归并事件；待归并作品仍在信息流，不能伪造事件标题补位。

数据全量接入与模型批量处理分开：事件归并每轮最多40篇、每批12篇，验证成功后逐批保存；后续轮次从未归并作品继续，不要求一次调用处理上千篇。模型调用仍受当前小时额度约束，输入字符和单事件40篇/100条评论限制继续生效。大事件保留完整数据、提示待分块处理，不能生成假装覆盖全部材料的摘要。后台常驻任务队列、大事件分块汇总及MongoDB持久化仍是后续开发项。

## 验证

隔离测试覆盖全部分页、详情并发上限、评论ID与父子关系、快照、缓存、取消、重复分页和失败拒绝；原有模型证据测试继续运行。真实只读验证不需要调用模型。
